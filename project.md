# Визитка — Маргарита Антонова, AI Визуал

## Что это за проект

Интерактивная цифровая визитка-лендинг для Маргариты Антоновой — AI-художника и нейрофотографа. Это одностраничный сайт, который заменяет классическую бумажную визитку: показывает портфолио, услуги, цены и способы связи. Сайт собран в один HTML-файл и опубликован на GitHub Pages.

**Живая ссылка:** https://margoneiro.github.io/vizitka/

---

## Для кого

Потенциальные клиенты, которые хотят:
- заказать нейрофото (портреты, военная тематика, природа)
- заказать нейровидео (реалистичное или анимационное)
- заказать именной флаг с позывным
- узнать цены и связаться с автором напрямую

## Дизайн

- **Стиль:** тёмный космический / dark luxury
- **Фон:** тёмно-синий (#06081e) с анимированным звёздным небом (canvas)
- **Акцентный цвет:** фиолетовый (#c084fc) и голубой (#38bdf8)
- **Шрифты:** Playfair Display (курсив, заголовки) + Raleway (основной текст)
- **Эффекты:** стеклянный морфизм (glass morphism), градиентный текст, падающие звёзды
- **Адаптив:** на мобильном фото сверху, текст снизу — без текста поверх лица

---

## Технический стек

- **Формат:** один HTML-файл (все фото и видео зашиты как base64)
- **Сборка:** PowerShell-скрипт `gen_vizitka.ps1` объединяет `vizitka_p1.html` + медиафайлы + `vizitka_p2.html`
- **Хостинг:** GitHub Pages → репозиторий `MarGoNeiro/vizitka`
- **JS/CSS:** чистый Vanilla JS + CSS без фреймворков
